# Бінарка — Serhii Romaniv

A Takuzu (binary puzzle) game: a seeded generator that guarantees exactly one solution, a rule checker, a hint engine that explains each hint in one Ukrainian sentence, a CLI, and a Ukrainian play page (4×4, 6×6, 8×8, rule highlighting, hints, reset, rules block).
